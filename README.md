# 👗 Fashion Recommendation System

A modern and responsive fashion recommendation website built using HTML, CSS, and JavaScript.

The website allows users to explore fashion products, search for outfits, filter products based on category and color, select their preferred fashion style, save favorite products, and add products to a shopping cart.

---

## 🌟 Features

- 🏠 Modern and responsive homepage
- 👗 Fashion product recommendations
- 🔍 Search outfits by name
- 🏷️ Filter products by category
- 🎨 Filter products by color
- ✨ Filter products by fashion style
- ❤️ Add products to favorites
- 🛍️ Add products to shopping cart
- 💰 Dynamic cart total calculation
- ❌ Remove products from cart
- 📱 Fully responsive design
- 🎯 Category-based product exploration
- ⚡ Dynamic product rendering using JavaScript

---

## 🛠️ Technologies Used

- HTML5

- JavaScript
- Google Fonts
- Responsive Web Design

## 💡 How the Recommendation System Works

The current version uses predefined product data and user-selected preferences.

The products contain information such as:

```text
Product Name
Category
Style
Color
Price
Rating
```

JavaScript filters the products according to the user's selected preferences.

For example:

```text
User selects → Casual

        ↓

System checks product style

        ↓

Products with "casual" style

        ↓

Displayed as recommendations
```
